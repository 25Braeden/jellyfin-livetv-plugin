# Manual setup: local Jellyfin 12.2 stack, before Gate 3

The 12.2 stack (docker-compose.12.yml) is at http://localhost:8097. The Gate 3 script
(`scripts/gate3_test.py`) configures the plugin itself; it needs the server prepared as below.
Everything happens in the browser at http://localhost:8097 unless a command is shown.

## 1. Startup wizard

- Create the admin user. The name is free (the scripts find the administrator through the API
  key, not by name — `scripts/nocode_experiment.py` `admin_user_id`); `admin` is a good choice.
- The admin password is never used by the scripts. Choose anything you can remember.
- No libraries are needed in the wizard; the test adds its own (`scripts/library_fixture.py`).

## 2. Test users A, B, C

Dashboard > Users, create three users named exactly `A`, `B`, `C`:

- Leave the password **empty** for all three. The scripts log in with an empty password
  (`AuthenticateByName` with `"Pw": ""`, scripts/nocode_experiment.py `login`).
- A and B: keep Live TV access ON (default).
- C: turn Live TV access OFF (user > Access > "Allow Live TV access" unchecked). Gate 3 expects
  C to be rejected natively on `/LiveTv/*` with 403.

## 3. API key

Dashboard > API Keys > add a key (any name). Put it in `.env` in the repo root (gitignored):

```
JELLYFIN_API_KEY_12=<the key>
```

The 10.11 stack's key stays in `JELLYFIN_API_KEY`; the scripts pick the variable named by
`LIVETV_API_KEY_VAR` (default `JELLYFIN_API_KEY`). Keys are never printed by the scripts.

## 4. Live TV tuners

Dashboard > Live TV > Tuner Devices, add two "M3U Tuner" devices:

| Tuner | Path (inside the container) | Stream limit |
|---|---|---|
| tuner 1 | `/tuners/tuner1.m3u` | **1** |
| tuner 2 | `/tuners/tuner2.m3u` | **1** |

The stream limit of 1 is required: Gate 3 section 7 expects a second channel on a busy tuner to
fail with 409 "tuner busy" (set the way `scripts/nocode_experiment.py` `setup()` sets
`TunerCount=1`).

## 5. Listings provider (XMLTV)

Dashboard > Live TV > Listings Providers, add an "XML TV" provider:

- Path: `/tuners/guide.xml`
- Enable for all tuners: yes

`tuners/guide.xml` is gitignored and is (re)generated by the test itself before each guide
refresh (`gate3_test.py` `fresh_guide`); the provider just has to point at that path. Without it
the guide checks in sections 2 and 13 have no programmes and section 13 aborts.

## 6. Deploy the plugin

```
scripts/deploy_local12.sh
```

This builds the plugin (net10.0) and installs it into `local12/config/plugins/LiveTvAccess_0.1.0.0/`
with `targetAbi: 12.2.0.0`, then restarts `jellyfin-dev-12`. 12.2 loads a plugin only when the
server version is >= targetAbi (12.2 source:
`Emby.Server.Implementations/Plugins/PluginManager.cs:745-755`), and every DLL in the meta.json
`assemblies` whitelist must exist in the plugin folder or the plugin is marked Malfunctioned
(`PluginManager.cs:886-935`) — the script's manifest satisfies both.

Check Dashboard > Plugins: LiveTvAccess should be Active.

Do NOT configure the plugin yourself: Gate 3 saves the tuner/user config in its section 1. Until
then the plugin fails closed (non-admins get no Live TV) — that is expected.

## 7. Run Gate 3 against 12.2

```
export LIVETV_BASE=http://localhost:8097
export LIVETV_JELLYFIN_CONTAINER=jellyfin-dev-12
export LIVETV_FAKESTREAMS_CONTAINER=fakestreams-12
export LIVETV_LOCAL_DIR=local12
export LIVETV_API_KEY_VAR=JELLYFIN_API_KEY_12
python3 scripts/gate3_test.py
```

Host prerequisites (same as the 10.11 runs): `ffmpeg` on the Mac (library fixture generates the
test MP3) and `node` (section 20 checks the settings page script parses).

Note: Gate 3 temporarily edits `tuners/tuner2.m3u` (shared with the 10.11 stack) and restores it.
Don't run Gate 3 against both stacks at the same time.
